# 1. Record architecture decisions

Date: 2026-11-24 · Status: accepted

## Context
The build spec asks for significant decisions to be written down so the team can follow why the POC looks the way it does.

## Decision
We keep lightweight ADRs (context, decision, consequences) in `docs/adr/`, numbered in order. A decision that changes the folder layout from the spec gets an ADR.

## Consequences
New contributors can read the ADRs instead of reverse-engineering choices from code.
